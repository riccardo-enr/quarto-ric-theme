# quarto-ric-theme

A reusable Quarto format extension providing light and dark themes with multiple color palettes.

## Installation

```bash
quarto add riccardo-enr/quarto-ric-theme
```

## Usage

In your `_quarto.yml`, choose a palette:

```yaml
# Riccardo palette (egyptian blue, bronze spice, soft peach)
format:
  ric-theme-ric-riccardo: default

# Genoa palette (red, yellow, dark teal)
format:
  ric-theme-ric-genoa: default

# Stream palette (charcoal blue, autumn leaf, sandy brown)
format:
  ric-theme-ric-stream: default
```

Each palette includes both light and dark mode variants.

## Palettes

### Riccardo
- Egyptian Blue `#38369a` — Bronze Spice `#cc5803` — Soft Peach `#ecce8e` — Grey Olive `#818d92` — Ink Black `#011627`

### Genoa
- White `#ffffff` — Dark Teal `#05232f` — Red `#ad1919` — Yellow `#ffd400`

### Stream
- Charcoal Blue `#2b3a4e` — Blue Slate `#4a5a75` — Autumn Leaf `#e56b25` — Sandy Brown `#f2a365` — Gunmetal `#3b3b3b`
